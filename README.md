# Mayank Mittal – Portfolio

A modern developer portfolio showcasing my projects, skills, and experience with a focus on clean UI, performance, and real-world engineering practices.

## 🚀 Tech Stack
- React
- Three.js / React Three Fiber
- GSAP
- Tailwind CSS
- Vite

## ✨ Features
- Interactive and responsive UI  
- Smooth animations and transitions  
- 3D elements for visual storytelling  
- Performance-optimized for all devices  
- Clean, scalable code structure  

## 📂 What You’ll Find
- Selected projects with clear problem statements  
- Technologies used in each project  
- Brief explanations of design and engineering decisions  

## 🛠️ Setup & Run Locally

```bash
git clone https://github.com/Chief-myk/Mayank-portfolio.git
cd Mayank-portfolio
npm install
npm run dev
```

### Open http://localhost:5173 in your browser.
